# Goao_iwo9 — سرویس اشتراکیِ ربات روبیکا (دو ربات جدا)

یک سرویس اشتراکی برای ابزار روبیکا با **دو ربات تلگرامیِ کاملاً جدا**:

- **ربات مالک (پنل مرکزی):** فقط برای تو — مدیریت مشتری‌ها، آمار، ورکرها.
- **ربات مشتری:** مشتری‌ها استارت می‌زنن، اشتراک می‌خرن، و کار می‌کنن.

> منطق لاگین/ارسال/PDF/اتصال (`rubika_client`, `worker`, `account_conn`,
> `crypto_util`, `pdf_export`) **مو‌به‌مو از پروژه‌ی قبلی** نگه داشته شده.
> حذف‌شده‌ها: اتومیشن، موتور مولد، و بکاپ دستی.

---

## 🔐 جداسازی کامل

- **دو توکن، دو پروسه، دو دیتابیسِ منطقیِ جدا:**
  - `data/customer.db` (`db.py`) — دیتای عملیاتیِ مشتری‌ها (اشتراک، اکانت‌ها،
    پرداخت‌ها، تنظیمات، ریت‌لیمیت). ربات مشتری فقط همین رو می‌بینه و همیشه
    محدود به آیدیِ خودِ مشتری.
  - `data/central.db` (`central_db.py`) — دیتای فقط‌مالک (حالت تعمیر، بکاپ،
    پیام‌های همگانی، لاگ ممیزی). **ربات مشتری این رو اصلاً import نمی‌کنه.**

---

## 🤖 ربات مشتری

- استارت → پنل + بالای پنل: «X روز مونده» / «منقضی شده».
- خرید اشتراک: ۳روزه=۵، هفتگی=۸، ماهانه=۲۰ (USDT/TRC20).
- پرداخت: ربات آدرس ولت می‌ده → مشتری هش تراکنش می‌فرسته → **تأیید خودکار با
  TronGrid** (مبلغ دقیق + آدرس مقصد + تأییدشده + هر هش فقط یک‌بار).
- امکانات: افزودن اکانت، ارسال (مارکر، با منطق پروژه‌ی قبلی)، ایمپورت عکس پیوی →
  PDF، کیف پول، چک‌حساب (تعداد/سالم‌بودن اکانت‌ها). **بدون محدودیت تعداد اکانت.**
- لاگ‌های هر مشتری توی پیویِ خودش هم میاد.

## 🎛 پنل مرکزی (مالک)

- داشبورد آمار (مشتری‌ها، اکانت‌ها، ارسال، درآمد، سلامت کلی).
- پروفایل هر مشتری + جستجو + رتبه‌بندی.
- افزودن مشتری دستی + کم/زیاد کردن زمان + مسدودسازی فوری/رفع مسدودی.
- پیام همگانی.
- مدیریت + لاگ ورکرها (مثل پروژه‌ی قبلی).
- حالت تعمیر + بکاپ فوری.

## 🛡 اشتراک و امنیت

- انقضای خودکار + هشدار ۲ روز قبل.
- قفل زمانِ ضددستکاری (بر اساس زمان سرور؛ rewindِ ساعت نادیده گرفته می‌شه).
- Rate-limit: ۱۵ اکشن / ۲ دقیقه → بیشتر = مسدودیِ خودکار + لاگ.
- آنتی‌فراد تراکنش: هر هش فقط یک‌بار (ستون `tx_hash` یکتا).
- رمزنگاری دیتای حساس at-rest (Fernet).
- حالت تعمیر + بکاپ خودکارِ سیستمی (هر دو دیتابیس + سشن‌ها).
- گروه لاگِ مرکزی: همه‌چیز یکجا (استارت، خرید، افزودن اکانت، شروع ارسال، خطاها،
  متن مارکر مشتری، فایلِ ایمپورت تصاویر، لاگ ورکرها، رفتار مشکوک).

## ⚡ راه‌اندازی

```bash
git clone https://github.com/willbedoneuw/Goao_iwo9
cd Goao_iwo9
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # مقادیر رو پر کن
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"   # WORKER_SECRET
```

دو پروسه رو جدا اجرا کن (هر کدوم با MODE خودش):

```bash
MODE=owner    python main.py     # پنل مرکزی
MODE=customer python main.py     # ربات مشتری
```

یا با داکر: `docker compose up -d --build` (دو سرویس owner و customer).

> اول هر دو ربات رو ادمینِ گروه لاگ کن تا لاگ‌ها بیاد.

## 🧩 ساختار

| فایل | نقش |
|------|-----|
| `main.py` | انتخاب نقش با `MODE` (owner/customer/worker) |
| `config.py` | همه‌ی تنظیمات |
| `owner_bot.py` | پنل مرکزی |

| `db.py` | دیتابیس عملیاتیِ مشتری (`customer.db`) |
| `central_db.py` | دیتابیس فقط‌مالک (`central.db`) |

| `ratelimit.py` | ضد‌فلود + مسدودیِ خودکار |
| `logbus.py` | لاگِ گروه مرکزی + پیویِ مشتری |
| `backup.py` | بکاپ خودکار + حالت تعمیر |
| `rubika_client.py` `worker.py` `worker_api.py` `account_conn.py` `crypto_util.py` `pdf_export.py` | **عیناً از پروژه‌ی قبلی** |
